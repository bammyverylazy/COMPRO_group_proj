## CPEgg Hatch CPEgg Hatch: Gamified Reading Timer Application
```(2026/1) 01204113 Computer and Programming for Computer Engineers ```

โครงงานซอฟต์แวร์ เรื่อง การพัฒนาระบบจับเวลาอ่านหนังสือในรูปแบบเกม CPEgg Hatch CPEgg Hatch: Gamified Reading Timer Application จัดทำขึ้นโดยมีวัตถุประสงค์เพื่อพัฒนาระบบจับเวลาอ่านหนังสือ โดยประยุกต์ใช้แนวคิดเกมมิฟิเคชัน (Gamification) รูปแบบการฟักไข่ดิจิทัล สำหรับส่งเสริมวินัยและแรงจูงใจในการเรียนรู้ของนิสิตภาควิชาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยเกษตรศาสตร์ โดยโครงงานนี้ได้นำหลักการเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming: OOP) ตามที่ได้ศึกษาในชั้นเรียน ในส่วนของ Encapsulation, Inheritance, Polymorphism และ Abstraction เพื่อออกแบบโครงสร้างสถาปัตยกรรมซอฟต์แวร์ให้มีความยืดหยุ่น เป็นโมดูลาร์ (Modular) และง่ายต่อการบำรุงรักษาในอนาคต
